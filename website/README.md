# Trang tải Em Trợ Lý

Thư mục này lưu giao diện trang tải và logo của Anh Lập Trình. Website đang
được phục vụ riêng trên VPS; cập nhật thư mục này trên GitHub không tự triển
khai website lên VPS.

- `index.html`: trang tải, dùng phông Roboto từ Google Fonts.
- `static/logo-anh-lap-trinh.png`: logo được tham chiếu từ `/static/`.
- Nút Windows trỏ đến `caidattroly.exe` của GitHub Release mới nhất. Đẩy
  code lên nhánh `main` tạo artifact kiểm tra, không tự tạo Release chính thức.
- macOS và Ubuntu chưa có nút tải chính thức trên trang.

Đây chỉ là mã giao diện; thư mục không bao gồm backend quản lý, dữ liệu bot,
thông tin xác thực hay bộ cài EXE.
